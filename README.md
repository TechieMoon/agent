# 만들면서 배우는 AI 에이전트 개발 입문+실전 — 공부 노트

『만들면서 배우는 AI 에이전트 개발 입문+실전』(한빛미디어)을 공부하면서 직접 실행해 본 코드와 정리 문서를 **책 목차 순서대로** 모아둔 복습용 저장소입니다.

- 책 예제 원본: [gongwon-nayeon/hanbit-aiagent](https://github.com/gongwon-nayeon/hanbit-aiagent)
- 날짜별 학습 기록은 [hanwha_0902](https://github.com/TechieMoon/hanwha_0902)에 있고, 여기는 같은 내용을 **책 챕터 기준**으로 재정리한 것입니다.
- 폴더는 `chXX/`(챕터), 파일은 `절번호_내용` 형식입니다. 예) `ch05/5.2_langgraph_state_reducer_node_edge.ipynb` = 5장 2절
- 같은 이름의 `.md` 파일이 그 코드의 정리 문서입니다.

## 실행 환경

```bash
# 책 4.2절 방식 (아나콘다 가상 환경)
conda create -n langgraph python=3.12
conda activate langgraph
pip install -r requirements.txt
```

루트에 `.env` 파일을 만들고 `.env.example`을 참고해 API 키를 넣어주세요. (`.env`는 `.gitignore`에 포함되어 있어 커밋되지 않습니다.)
